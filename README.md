# 星弹骑士 StarShot Knights

一个像素风格的回合制战术小游戏：**蓄力射击 + 伙伴部署**。

**想玩？** 下载 `index.html`，用 Chrome / Edge 双击打开就行。不用安装任何东西。

> 这个仓库只放**可玩的成品**。源码不公开。

## 怎么玩

| 操作 | 做法 |
|---|---|
| 移动 | 点绿色格子，走一格 |
| 射击 | 按住鼠标蓄力，松手发射星弹（右键 / Esc 取消） |
| 回血 | 击杀敌人时吸收星能 |
| 部署伙伴 | 第二关：点右侧卡片，再点蓝色格子 |
| 换位 | 点场上的伙伴，再点蓝色格子（两步内） |

第二波来之前可以选一种新弹药：**电弧星弹**（连锁电击）或 **黏黏星弹**（黏住来路）。
